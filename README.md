# Taco Diario

Una hoja de taco al día para estar al día y estimular el cerebro: imagen generada, buena noticia, vídeo, artículo, reel, libro, película, serie, canción, frase célebre, personaje, planta, refrán, frase hecha, palabra, dato, concepto, reto, pregunta y micro-hábito.

Es una app instalable (PWA): ábrela en el móvil y añádela a la pantalla de inicio. Funciona sin conexión. Los guardados, el progreso y la racha se quedan en el propio dispositivo.

Estos archivos se generan con `node dosis/build-app.mjs` en el repositorio de origen; no los edites a mano. La tarea diaria solo actualiza `noticias.json`.
